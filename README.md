# RandomFS Version 0.3
---
## New Features
- Chaos mode, it shows different files each time when mounted. but you can use the normal mode without using the "--chaos" part

## Bug Fixes
- Fixed some unseen bugs

---
## How to use
- Chaos mode: ./randomfs --chaos entropy.img mnt
- Normal mode: ./randomfs entropy.img

# How to compile
- Make sure you have the dependencies
- Run "make" in the root of the source code using the terminal
- Takes around 2 seconds to compile
